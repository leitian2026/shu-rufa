# 我的输入法(拼音 / 笔画 / 英文)

自用 Android 输入法。只申请联网权限(用于「词库管理」下载词库,以及打开「输入翻译」后调用微软 / 谷歌翻译;翻译没打开时键盘不联网),零第三方依赖,Kotlin 自绘键盘。

## 构建(只能手动触发)

1. 把本目录推到 GitHub 仓库。
2. 仓库页 → **Actions** → *Build release APK (manual)* → **Run workflow**。
3. 跑完后在该次运行页底部的 Artifacts 下载名为 `myime-v版本号-build序号` 的产物,解压得到 `app-release.apk`。
4. 手机安装 → 打开「我的输入法」App → 按两个按钮启用并切换。

不会自动构建:工作流只有 `workflow_dispatch` 触发器。

### 签名与覆盖安装
覆盖安装需要三件事同时满足:**包名不变、签名密钥不变、versionCode 只增不减**。

- 包名固定为 `com.example.myime`。
- 签名:仓库里自带 `signing/myime.jks`(密码 `myime-self-use`,别名 `myime`),每次构建都用它,所以后续版本可以直接覆盖安装。
- versionCode 由版本号加 CI 运行序号自动算出,同一版本号重复构建也会继续增大。
- ⚠️ 这把密钥在仓库里,**仓库请设为私有**。如果要公开仓库,请改用 Secrets:删掉 `signing/myime.jks`,自己生成密钥,
  然后在仓库 Settings → Secrets and variables → Actions 添加 `KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`。
  有 Secrets 时会优先使用 Secrets。
- 换了密钥后,手机上用旧密钥装的版本必须先卸载一次。

```
keytool -genkeypair -v -keystore release.jks -alias myime -keyalg RSA -keysize 2048 -validity 36500
base64 -w0 release.jks        # macOS: base64 -i release.jks
```

### 版本号怎么改
只改根目录 `version.properties`,格式是 **主版本.次版本.修订号**(例如 1.4.2):

| 改动类型 | 怎么升 | 例子 |
|---|---|---|
| 大版本:大改版、重大功能变化 | 主版本 +1,次版本和修订清零 | 1.4.2 → 2.0.0 |
| 小版本:新增功能,向下兼容 | 次版本 +1,修订清零 | 1.4.2 → 1.5.0 |
| 修订:只修 bug、调细节 | 修订 +1 | 1.4.2 → 1.4.3 |

- 还没稳定时用 `0.x.y`,觉得可以长期用了再发 `1.0.0`。
- 不用手动管 versionCode,构建时自动计算:`主×10,000,000 + 次×100,000 + 修订×1,000 + 构建号`。
- 每次构建的产物名里带版本号和构建序号,如 `myime-v0.1.0-build3`,方便对应。

## 界面与使用
界面排版和配色参考你给的截图:浅蓝灰键盘底、白色按键带底部阴影、功能键偏深、蓝色主按钮。

- **上方两条白色区域**:上条是拼音/笔画预览;下条空闲时是工具栏,输入时换成候选词(第一个蓝色)。
  工具栏 6 个图标,从左到右:**设置**(打开本应用)、**切换输入法**、**表情**、**光标编辑**、**剪贴板**(剪刀图标)、**收起键盘**。当前打开的页面对应的图标会高亮。
- **拼音页**:26 键,键帽大写。左下角「笔画」键切到笔画;输入中它变成「分词」,用来标出音节边界(如 `xi'an`)。
- **笔画页**:横 一(h) 竖 丨(s) 撇 丿(p) 点 丶(n) 折 ㄥ(z);`*` 是通配任意一笔;`ab` 切回拼音;左侧竖排标点键(，。？！…)。
  宽屏(平板/横屏)左边多一块数字区,和截图一致。输入中右下角的回车键变成「清除」。
- **中/英**:在最近用的中文方式和英文之间切换。**符**:符号页;**123**:数字页。
- **光标编辑页**(工具栏第三个图标):Tab、复制、粘贴、剪切、全选、方向键、开头/末尾、Del,「选择」打开后方向键变成扩选;右下蓝色「返回」。
- **表情面板**:共 700 多个、8 个分类,上下滑动;点底部分类标签会带动画滚动过去;最近用过的排在最前面(只存内存)。分类和表情可以直接改 `app/src/main/assets/emoji.txt`。
- **剪贴板**:自动记录你复制过的文字(最近 30 条,新的在前)。点一条 = 粘贴并回到键盘;点右侧 × 删除这一条;右下「清空」删除全部。
  只保存在内存里,进程结束就没有了,不写入存储;密码管理器等标记为"敏感"的复制内容不会被记录。
  只有本输入法是当前使用的输入法时才能读取剪贴板(系统限制)。
- 空格选第一个候选;回车在有输入时原样上屏;删除键和方向键长按连发。
- 密码框强制英文且不使用组合区;数字/电话框直接进数字页。

## 输入翻译
- **打开 / 关闭**:工具栏第一个按钮(功能页)里的「译」。打开后这一格整格变成**绿底白字**(键盘其他地方配色不变),翻译框和悬浮键盘顶上的拖动条也用绿色,一眼能分辨现在是不是翻译状态。再点一次关掉。开关会记住。
- **翻译框**:打开后候选栏上面多出一行:`[中›英] [ 原文…… ×] 完成`。键盘(拼音 / 笔画 / 英文 / 表情 / 符号 / 剪贴板)打的字都先进这个框,**停下约 0.35 秒就翻译,译文实时出现在目标输入框里**(带下划线,下一次译文直接替换它)。
- **完成**:点框右边的「完成」或键盘上的回车键(有字时它显示「完成」)——译文留在目标输入框里,翻译框清空,输入结束。翻译框是空的时候,回车键照常是目标输入框的「搜索 / 发送 / 换行」。译文还没回来就点完成,会等它回来再收尾。
- **×**:清空原文,目标输入框里的译文一起清掉。框空时右边是「关闭」,等于关掉输入翻译。
- **方向**:点左边的 `中›英` 换下一个方向(中›英 → 英›中 → 中›日 → 中›韩 → 中›法 → 中›德 → 中›俄 → 中›西),框里有字会马上按新方向重翻。
- **引擎**:功能页里的「翻译:微软 / 谷歌」点一下互换**主用**。默认微软(Edge 浏览器内置翻译的接口,国内能直连);主用失败(超时 / 被拒)自动换另一个试,刚失败过的引擎 1 分钟内先放到后面,不会每个字都等它超时。同一句话翻过的有缓存,不再联网。
- **只在普通文本框里用**:密码、数字、电话、邮箱框不翻译。点了应用里别处(光标离开译文),就结束这一次翻译,译文留在原来的框里。
- **省电**:没有任何定时轮询,只有「翻译框的原文变了」这一个触发。
  - 停 0.6 秒才发请求,连续打字不会每个字都联网(`TRANS_DEBOUNCE_MS` 可调,越长越省)。
  - 一次只发一个请求;排队里已经过期的、以及要换备用引擎前原文已变的,都不再发。
  - 连接读完不断开,复用系统连接池,省掉每次的 TCP + TLS 握手;超时 4 / 6 秒;微软令牌缓存约 10 分钟。
  - 发请求前先看有没有网,没网直接标「翻译失败」不空等超时,并只在没网时临时挂一个网络回调,网络一回来重试一次就摘掉。
  - 键盘收起时丢掉没发出的翻译、放掉请求和网络回调;再打开时才补翻。
  - 翻译框只在内容有变化时重画,打字过程中不重新排版。
- **隐私**:只有翻译框里的原文会发出去(发给微软或谷歌),目标输入框里别的内容不会读取、不会发送。

## 词库
`app/src/main/assets/` 里是启动用的**小样本**(约 220 词、66 字),只够验证流程。
换完整词库(Rime 格式):
```
python3 tools/convert_rime_dict.py pinyin app/src/main/assets/pinyin.txt 8105.dict.yaml base.dict.yaml
python3 tools/convert_rime_dict.py stroke app/src/main/assets/stroke.txt stroke.dict.yaml
```
词库越大,启动加载越慢、APK 越大,建议从单字表 + 基础词库开始。
雾凇拼音是 GPL-3.0,若基于它的数据公开发布,需遵守 GPL。

## 动画与流畅度
- 所有动画共用 `Motion.kt` 里的 **360ms + 同一条缓动曲线**(范围 300–450ms),要整体调快慢只改一处。
- 动画只改 alpha / translationY,不触发重新布局;键盘高度在所有模式下相同。
- 键盘整体是一个自绘 View,`onDraw` 不分配对象;按键高亮消退按帧时间统一推进。
- 词库查询在后台线程,不占用主线程。
- 候选栏的惯性滑动用的是系统 OverScroller,属于物理滚动,不受固定时长控制。

## 已知限制 / 后续
- 还没有候选词展开面板、主题自定义;中文还没有整句智能组词,也没有中文联想。
- 表情不含肤色、组合(家庭、职业)类的复杂表情;显示依赖系统的表情字体。
- 手机屏幕(宽度 < 600dp)用紧凑尺寸,笔画页没有数字区。
- 自带笔画样本为手工录入,笔顺以正式字表为准。
- targetSdk 为 34,避免 Android 15 强制全屏边到边布局影响键盘底部。


## 功能页与键盘调节

- 工具栏第一个按钮(原来的设置)现在打开**功能页**:中英切换、拼音笔画、数字、符号、表情、剪贴板、光标编辑、切换输入法、键盘调节、输入法设置、收起键盘。点一格执行一个功能。
- **键盘调节**(功能页里):键盘变暗,四角出现蓝色折角。拖左 / 右把手改宽度,拖上把手改高度(向上长高),拖其他位置整体移动(可左右移,也可抬离屏幕底部);「重置」恢复默认,「确认」保存。没点确认就收起键盘 = 放弃这次调节。
- 尺寸只存几个数字(高度、宽度比例、左边距、离底距离),在 SharedPreferences 里。

## 键盘选择

- 工具栏第二个按钮(键盘图标)打开**键盘选择**:拼音26键 / 笔画输入 / 英文26键 / 切换输入法(系统选择器)。当前用的那一项显示蓝色,点一项就切过去并回到键盘。密码框里只能选英文。

## 英文页的大小写键

- 左下的箭头键三种状态,每点一下换一个:小写(空心箭头)→ 锁定大写(蓝底,箭头带下划线)→ 只大写下一个字母(实心箭头,打出一个字母后自动变回小写)→ 小写。
- 句首等编辑框要求大写时,会自动进入「只大写下一个字母」。

## 剪贴板多选 / 调节遮罩(更新)

- 剪贴板:点一条 = 粘贴;**长按一条 = 进入多选**,每条前出现圆圈,点哪条选哪条,标题显示「已选 n 项」;底部是「取消 / 全选(再点取消全选)/ 删除(n)」。离开面板或点「取消」会退出多选,不会残留。「清空」仍是全部删除。
- 键盘调节:遮罩只盖在输入法(候选栏 + 键盘)上;拖**上面两个角**可以同时改宽度和高度。

## 更新:功能页精简、去掉切换动画

- 功能页只保留别处没有的功能:**键盘调节**、**输入法设置**。中英切换、拼音笔画、数字、符号在键盘按键上;表情、光标编辑、剪贴板、收起键盘在工具栏;切换输入法在「键盘选择」里。
- 切换页面 / 面板 / 键盘模式时不再有滑入、淡入动画,直接显示。(按键按下的高亮渐隐、候选栏与工具栏之间的淡入淡出仍保留。)

## 更新:去掉全部动画

按键高亮的渐隐、候选栏与工具栏之间的淡入淡出、面板滑入、表情分类的滚动动画、列表惯性滚动的自定义曲线都去掉了:按下就高亮,松手就恢复,切换页面直接显示。(Motion.kt 现在没有被用到。)


## v0.4:词库管理(下载)与词频学习、英文补全/联想/纠错

### 词库管理
- 功能页(工具栏第一个按钮)里的「词库管理」,或应用首页的第 3 个按钮,打开词库管理页:笔画 / 拼音 / 英文三个词库包,各有「下载并安装 / 取消 / 删除」,带进度条。
- **这是本应用唯一联网的地方**,只在点下载时访问网络;为此清单里现在申请了 `INTERNET` 权限。键盘服务(`MyImeService`)的代码里没有任何联网。
- 数据来源(都在 `DictInstaller.kt` 的 `DictPacks`,要换源改这里):
  - 笔画:rime-stroke 的 `stroke.dict.yaml`(LGPL-3.0,含繁体和扩展区生僻字),字频取自雾凇 `8105.dict.yaml`。
  - 拼音:雾凇拼音(GPL-3.0)的 `8105 / base / ext / 41448(大字表,生僻字)`,再加 rime-luna-pinyin 的 `luna_pinyin.dict.yaml`(LGPL-3.0,繁体字,权重压到最低,排在简体后面)。
  - 英文:Norvig 的 `count_1w.txt`(单词词频)和 `count_2w.txt`(双词,做联想),数据来自谷歌语料,代码 MIT。
  - 自用没问题;若要公开发布 APK,雾凇的 GPL-3.0 需要遵守。
- 下载后在手机上直接转换成本 App 的格式(`DictConvert.kt`,逐行流式处理、不整个读进内存):
  拼音词库超过「词条上限」(默认 20 万,页面里可切 10 / 20 / 40 万)时,按权重从低到高砍掉多字词,**单字、繁体、生僻字全部保留**。
- 如果分支名或文件路径变了导致下载失败,页面会显示失败原因;可手动把原始文件放进 `raw/` 再点「下载并安装」(下载失败时会改用 `raw/` 里已有的文件)。
- 连不上 GitHub 时,可在页面里填「镜像前缀」(先试 前缀+原地址,再直连)。

### 词库文件夹(存放与手动部署)
```
/sdcard/Android/data/com.example.myime/files/dicts/     (外部私有目录不可用时在应用内部 files/dicts/)
    pinyin.txt   stroke.txt   english.txt   english_bigram.txt    转换后的词库,运行时读取
    raw/                                                          下载的原始文件,可离线重新转换
```
- 运行时优先读这个文件夹;没有就用 `assets/` 里的内置小样本(英文没有样本,不装就没有补全,英文页保持原来的直接上屏)。
- 手动部署:把转换好的 `.txt` 直接放进去即可;每次弹出键盘时比较文件大小和修改时间,变了就自动重新加载,不用重启。
- 页面里显示了这个文件夹的完整路径(可长按复制)。

### 词频学习
- 拼音 / 笔画:选过的候选(点候选或空格上屏)记一笔,同一输入下选得越多排得越靠前。
- 英文:记你常打的词、词库里没有的新词(出现 2 次才收)、以及词和词的先后关系(用于联想)。
- 只存在应用私有目录 `files/user/`,不上传;密码框、网址/邮箱框、应用声明不要建议或个性化学习的输入框里不记录。
- 词库管理页里可以关闭学习、查看已学数量、一键清除。

### 英文输入
- 普通文本框的英文页:字母进入组合区(带下划线),候选栏第一项是原样输入(单独的 i 变 I),后面是**前缀补全**,
  拼错且补不出几个词时给出**纠错**(少打 / 多打 / 打反 / 相邻键打错,必要时差两个字母)。
- 空格 = 原样上屏并加空格;点候选 = 上屏并加空格。设置里可以打开「空格自动改正」(默认关)。
- **联想**:上屏一个词后,候选栏给出下一个最可能的词(词库的双词表 + 你的习惯),6 秒不用会收回去露出工具栏;
  下一个词的补全也会按上一个词加权。
- 密码、网址、邮箱、数字框,以及没有装英文词库时,英文页仍是原来的直接上屏。
- 英文词表全小写;词首大写、全大写会跟着你的输入走。缩写(don't、I'm 等)是内置补上的。

### 低功耗相关(v0.4 后半)
- **候选只挑前 N 个**:拼音、笔画查询时用一个小的有序数组挑出最靠前的 30 / 40 个(我选过的优先,其余按词频),
  不再对整个匹配区间排序。输入 `a`、`zh`、笔画 `h` 这类很短的前缀时,匹配可能有几万条,以前要全排序。
- **英文纠错不产生临时字符串**:差一个字母的写法最多几百个、直接查哈希;差两个字母改成在"同一首字母、长度相差不超过 2"的词里
  算编辑距离(复用 3 行数组),只在差一个字母找不到时才跑。
- **词库按需加载、闲置释放**:只加载当前模式用到的词库(英文页才读英文词库、笔画页才读笔画词库);
  键盘隐藏 90 秒还没回来,或系统通知缺内存时(且键盘没在显示),全部释放,下次用到再读。
- **二进制缓存**:第一次从文本加载后,把排好序的数组写成二进制(应用内部 `files/dictcache/`),之后启动直接读回来,
  不再逐行切分、装箱和全量排序。源文件一变缓存自动作废。缓存可以随时删,会自动重建。
- **学习数据只在键盘隐藏时落盘**(以及输入框切换时),打字过程中不写文件。
- 开启 R8(代码和资源压缩)。若发布版出现闪退,把 `app/build.gradle.kts` 里 `isMinifyEnabled` / `isShrinkResources` 改回 `false`。
- 仍然没有:定时器、轮询、常驻线程(剪贴板用系统监听,不轮询)。
